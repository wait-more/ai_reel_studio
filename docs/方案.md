## 一、项目定位

创作流程里，剧本与物料多以**目录 + Markdown + 媒体文件**存放。本项目的目标是把这套结构**软件化**，而不是另起一套云端 CMS：

- **可视化呈现**：剧本树、物料网格、季/集层级浏览  
- **剧本管理**：多剧本组织与 Markdown 编辑  
- **物料管理**：角色定妆、场景、音频等文件夹的浏览与预览  
- **长剧支持**：多季、多集层级  
- **AI 互操作**：右侧嵌入式 Shell，快捷启动 opencode、dsh-tui 等；支持把当前文件/选区引用注入智能体  

用户配置的「项目根」通常是这类创作目录；与本仓库里用于打包的 `scripts/` 目录不是同一概念。

### 命名

- 产品名：**AIReelStudio**  
- 出发点：Reel（短视频/短剧）比 Video 更精准  
- Dart package 名：`ai_reel_studio`

| 维度 | 选型 |
|---|---|
| 框架 | Flutter 3.x / Dart ^3.6 |
| UI | Material 3 |

| 终端 | `kyroon_pty` + `xterm` |

### 2.2 目标选型（尚未落地或仅声明）

| 维度 | 原目标 | 现状 |
|---|---|---|
| 路由 | go_router | pubspec 有依赖，业务未用 |
| 数据库 | drift / SQLite FTS | ❌ 未接入 |
| 文件监听 | `watcher` | 实际为轮询扫描 |
| PTY | `flutter_pty` | 已换 **`kyroon_pty`** |
| 图片预览 | photo_view | 现用 `InteractiveViewer` |

## 四、数据模型

用户**项目根**下的创作目录约定（与本仓库 `scripts/pack_*.ps1` 无关）：

```
Project (可配置根目录)
├── Script (剧本)                → 001_悬疑_最后一次通话/
│   ├── meta.json（约定，进度现多用本地偏好）
│   ├── 剧本.md / 分镜.md …
│   ├── Material                 → 角色定妆照/、场景素材/ …
│   └── Season / Episode [可选]  → 剧集/1_觉醒/01_…
└── Shared（共享资源，按目录组织即可）
```

### 4.1 目录识别规则（已实现于 `DirectoryParser`）

```
Script / Season / Episode: 序号前缀目录约定 + 含剧本.md 等启发式
Material: 目录内媒体等非 .md 文件归到素材视图
```

### 4.2 SQLite 元数据 (drift) — 目标，未实现

```
tables: scripts / seasons / episodes / materials / start_cmds / sqlite_fts
```

当前：进度、快捷启动、工作区、Shell 会话均在 SharedPreferences；搜索为内存扫描。

## 五、Shell 集成设计

```
┌─ 右面板 Shell ─────────────────────────────────────────┐
│  [opencode] [dsh-tui] [bash] [+]       ← Tab 栏        │
├────────────────────────────────────────────────────────┤
│  $ opencode                                           │
│  > 进入 opencode 交互界面...                            │
│  > 用户直接在 app 内与 AI Agent 对话                     │
│                                                        │
├────────────────────────────────────────────────────────┤
│  快捷栏: [opencode] [dsh-tui] [ComfyUI] [自定义 +]     │
└────────────────────────────────────────────────────────┘
```

### 实现要点

1. **PTY**：`kyroon_pty`（Windows ConPTY）+ `xterm` 渲染  
2. **多 Tab**：每 Tab 独立 `TerminalSession`  
3. **快捷启动**：SharedPreferences 存 `StartCmd`（name/command/cwd 策略），非 SQLite  
4. **cwd 联动**：可按「项目根」或「当前选中目录」启动  
5. **Agent 引用**：可配置快捷键，向活跃智能体填入 `@相对路径#L…`（不回车）  
6. **会话恢复（一期，已实现）**：按项目持久化 Tab 列表、cwd、启动命令、面板显隐；重启后重建 PTY 并重拉命令；**不恢复**滚动缓冲与进程本身  
7. **Shell 类型**：Windows 默认 PowerShell

## 六、核心功能模块

### 6.1 项目树导航（左面板）

**已实现：**
- 树形展示项目根下剧本，识别扁平 / 多季多集  
- 过滤；新建顶层剧本、新建子文件夹；右键打开、资源管理器、重命名、复制、删除、设置创作进度  
- 进度徽章（本地偏好，非 meta.json）  

**目标尚未实现：**
- 树内 SQLite FTS；「在终端打开」等未接线项以 UI 为准  

### 6.2 工作区（中面板）

**决策：不做左右分屏预览**（省屏幕）；当前实现为 **编辑 ↔ 预览切换**，另有大纲轨与行号。

**已实现：**
- Markdown 多 Tab 编辑（自研高亮）、大纲、行号、工作区记忆  
- 物料网格浏览、导入、类型过滤、媒体预览与截帧  

**目标尚未实现：**
- 网格/列表切换、拖拽上传/移动、标签  
- 角色管理专页、生成/音效清单专页、音频波形  

### 6.3 嵌入式 Shell（右面板）

- 多 Tab、快捷启动、可折叠（折叠保活）  
- 会话一期恢复见上文「五」  
- Agent 文件/选区引用快捷键  

### 6.4 远程目录支持

- 设置中配置项目根（UNC / 绝对路径）  
- OS 层挂载；应用不实现 SMB/SSHFS  
- 目录刷新：周期扫描（非可靠 file watcher 事件）
