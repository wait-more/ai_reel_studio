# AIReelStudio 技术方案

> 最后更新：2026-09-05
> AI 短视频创作工作台 —— 对 `scripts/` 目录层级进行可视化呈现与操作，内置 Shell 终端用于 AI Agent 快速交互。
>
> **实现状态**：可用预览 v0.1（见文末「十一、实现状态」）。本文以目标架构为准，进度以状态表为准。

## 一、项目定位

当前 `scripts/` 目录是用文档方式管理的（Markdown + 素材文件夹），本项目的目标是把这套目录结构**软件化**：

- **可视化呈现**：剧本树、物料网格、季/集层级的图形化浏览，替代纯文档操作
- **剧本管理**：多个剧本的新建、编辑、组织
- **物料管理**：每个剧本的角色定妆照、场景素材、音频素材、配音文件等
- **长剧支持**：多季、多集的层级化物料管理
- **AI 互操作**：右侧嵌入式 Shell，一键启动 opencode、dsh-tui 等 Agent 工具

### 命名

- 产品名：**AIReelStudio**
- 出发点：Reel（短视频/短剧）比 Video 更精准、更有辨识度
- Dart package 名：`ai_reel_studio`

## 二、技术选型

### 2.1 框架：Flutter (Dart)

| 维度 | 选型 | 理由 |
|---|---|---|
| **框架** | Flutter 3.x | 单代码库覆盖 Win/Linux/macOS/Android/iOS |
| **语言** | Dart | 类型安全 + 空安全 + Hot reload |
| **UI** | Material 3 | 三栏布局 + 树形导航 + Tab 工作区 |
| **状态管理** | Riverpod | 响应式、可测试 |
| **路由** | go_router | 导航 + 深链 |
| **终端模拟** | `xterm` (Dart) + `flutter_pty` | 终端渲染 + PTY 进程桥接 |
| **Markdown 编辑** | `flutter_markdown` + CodeMirror 风格编辑 | 纯编辑模式（不做分屏预览，见 6.2） |
| **数据库** | `drift` (SQLite) | 元数据缓存、全文搜索、进度追踪 |
| **文件监听** | `watcher` / `fseventsd` | 同步外部对 scripts/ 的改动 |
| **图片/视频预览** | `photo_view` / `video_player`/`media_kit` | 素材网格预览 |
| **远程目录支持** | OS 层挂载 + 配置 UNC/绝对路径 | SMB/SSHFS 由系统负责，app 只消费路径 |

**为什么是 Flutter 不是 Tauri/Electron：**

1. **Android 是确定路线**（后续阶段）—— Flutter 桌面→移动端适配成本几乎为零；Tauri 2.0 移动端生态较新
2. **UI 开发效率**：Hot reload 迭代快，三栏工作台这类工具型 UI 是 Flutter 强项
3. **单代码库**：Rust + Web 前端双栈维护成本高于纯 Dart

**已知 trade-off：**
- 终端体验略逊于 `xterm.js`，但本项目的 shell 场景是跑 opencode/dsh-tui 等 TUI 工具，`flutter_pty` + `xterm` 足够
- 远程目录协议需自行调研第三方包，推荐稳路线是 OS 层挂载（SMB/WebDAV/SSHFS），app 层不实现协议

### 2.2 平台优先级

```
Windows (主) → Linux (次) → macOS (顺带) → Android (后续)
```

## 四、数据模型

基于现有 `scripts/` 目录结构抽象：

```
Project (根目录: scripts/ 或其上级，可配置)
├── Script (剧本)                → scripts/001_悬疑_最后一次通话/
│   ├── meta.json (约定新建)     → 标签/简介/进度/创建时间
│   ├── 剧本.md 分镜.md 等       → 文档文件 (引用)
│   ├── Material (物料)          → 角色定妆照/, 场景素材/, 音频素材/
│   │   └── MaterialItem         → 每个 .mp4/.png/.wav/.pt
│   └── Season (季) [可选]       → 剧集/1_觉醒/
│       └── Episode (集)         → 剧集/1_觉醒/01_猝死穿书/
│           ├── 文档文件          → 剧本.md/分镜.md/配音脚本.md
│           └── Material          → 场景素材/, 配音素材/
│
└── Shared (共享资源)            → 003_配音/ 角色参考音等
```

### 4.1 目录识别规则

```
Script 识别: scripts/ 下形如 {序号}_{类型}_{剧名}/ 的目录
Season 识别: {剧集路径}/ 下 {序号}_{季名}/ 的目录
Episode 识别: 季下 {序号}_{集名}/ 的目录（或含剧本.md 的目录）
Material: 目录内非 .md 文件的归类展示
```

### 4.2 SQLite 元数据 (drift)

```
tables:
  scripts      (id, path, title, genre, tags, progress, created_at)
  seasons      (id, script_id, path, title, order)
  episodes     (id, season_id, path, title, order, progress)
  materials    (id, parent_path, name, type, size, mtime, tags)
  start_cmds   (id, name, command, cwd, icon)   ← 快捷启动配置
  sqlite_fts   (搜索索引)
```

## 五、Shell 集成设计

```
┌─ 右面板 Shell ─────────────────────────────────────────┐
│  [opencode] [dsh-tui] [bash] [+]       ← Tab 栏        │
├────────────────────────────────────────────────────────┤
│  $ opencode                                           │
│  > 进入 opencode 交互界面...                            │
│  > 用户直接在 app 内与 AI Agent 对话                     │
│                                                        │
├────────────────────────────────────────────────────────┤
│  快捷栏: [opencode] [dsh-tui] [ComfyUI] [自定义 +]     │
└────────────────────────────────────────────────────────┘
```

### 实现要点

1. **PTY 进程管理**：`flutter_pty` 创建伪终端进程，跨平台（Win 用 conpty/winpty，Unix 用 forkpty）
2. **终端渲染**：`xterm` (Dart) 渲染 PTY 输出，键盘输入写回 PTY
3. **多 Tab**：每个 Tab 一个独立进程 + PTY
4. **快捷启动**：`start_cmds` 表存预设命令（name/command/cwd/icon），点击即启动
5. **工作目录联动**：在左面板选中某个剧本/集时，快捷启动的终端自动以该目录为 cwd
6. **Shell 类型**：Windows 默认 PowerShell/cmd，Linux 默认 bash，可配置

## 六、核心功能模块

### 6.1 项目树导航（左面板）
- 树形展示 `scripts/` 下所有剧本，自动识别扁平（单集）vs 嵌套（多季多集）结构
- 右键菜单：新建剧本/季/集、重命名、删除、在终端打开
- 搜索框：文件名 + SQLite FTS 全文搜索内容
- 状态指示器：每集完成度（基于 meta.json + 文件 mtime 推断）

### 6.2 工作区（中面板，纯 Tab）
**决策：不做分屏预览**（用户已确认，省屏幕空间）：
- **剧本编辑器**：`CodeMirror` 风格 Markdown 编辑，语法高亮，纯编辑
- **物料管理**：缩略图网格/列表切换，拖拽上传/移动，标签管理
- **角色管理**：角色卡片 + 定妆照 + 关联素材预览
- **素材预览**：点击物料弹层（图片缩放、视频播放、音频波形）
- **生成清单/音效清单**：表格化视图，勾选打勾进度

### 6.3 嵌入式 Shell（右面板）
- 多 Tab 终端，独立进程
- 快捷启动预设（opencode、dsh-tui、ComfyUI、自定义）
- 可拖拽面板宽度，可折叠

### 6.4 远程目录支持
- 设置中配置项目根路径（支持 UNC `\\nas\share`、绝对路径）
- 推荐 OS 层挂载（SMB/WebDAV/SSHFS/OneDrive），app 不实现协议
- 需验证 `watcher` 与 `flutter_pty` 在 UNC 路径上的行为（搜索测试 stage）

## 八、技术调研风险点（Phase 0)

| 风险点 | 应对 |
|---|---|
| `flutter_pty` 维护状态 & Windows conpty 支持 | Phase 0 先写 PoC 验证；不行则换 `dart_pty` 或自封装 FFI |
| `xterm` (Dart) 的 Unicode/性能 | PoC 用 opencode TUI 实测渲染效果 |
| `watcher` 在 UNC/网络目录的事件可靠性 | PoC 验证；不可靠则该用轮询降级 |
| `video_player` 桌面端视频编解码 | 桌面优先试 `media_kit`（libmpv） |
| Markdown 编辑器组件成熟度 | 先试 `code_text_field`；不满足再评估自研 |
