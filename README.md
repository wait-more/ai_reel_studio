# AIReelStudio

面向 **AI 短剧 / 短视频** 的本地创作工作台：在真实项目目录上，把「看目录、改剧本、预览素材、跟 Agent 协作、调 ComfyUI」收进同一个三栏窗口。

> 版本 **v0.1.0** · Windows 优先 · 可用预览  
> 最后更新：2026-09-10

---

## 为什么用它

短剧团队常用「文件夹 + Markdown + 本地 Agent / Comfy」流水线，却要在资源管理器、编辑器、终端、浏览器之间反复切换——路径对不上、上下文丢、素材和剧本各开一窗。

**AIReelStudio 不另起云端 CMS，也不替代文件系统。**  
项目根仍是你指定的本地路径或 UNC；软件只做专用桌面壳，把已有目录变成可视化工作台。

| 痛点 | 本程序怎么解 |
|------|----------------|
| 剧本/季集目录深，翻文件夹慢 | 左侧树按剧本 / 季 / 集识别，可过滤、建档、标进度 |
| 改稿与素材脱节 | 中间栏文档编辑与素材网格同窗切换，媒体可预览 |
| Agent 在外部终端，手打路径 | 右侧嵌入真实 Shell；一键把文件/选区引用填进智能体 |
| 生成与项目目录分离 | 内置 ComfyUI 生成面板，模板与动作落在项目 `.aireel/` 下 |

---

## 亮点

1. **目录即项目** — 不绑云端库；换盘、换 NAS 路径即可换项目。  
2. **短剧语义树** — 自动识别剧本 / 季 / 集，进度徽章跟手。  
3. **三栏一体** — 树 · 文档/素材/生成 · Agent 终端，状态可跨启动恢复。  
4. **Agent 引用** — 把当前文件或选区写成 `@相对路径` / `#L行` 填入智能体（默认 `Ctrl+Alt+K`）。  
5. **Comfy 进工作台** — 导入 API JSON、动态表单提交本地/多实例；结果可预览并跳回素材栏。

## 界面与用法

首次启动进入设置，选择**项目根目录**（如 `D:\dramas` 或 `\\nas\share\scripts`）。  
注意：仓库里的 `scripts/` 是**打包脚本**，不是创作项目根。

```
┌─────────────┬──────────────────────────┬─────────────────┐
│  项目树      │  素材 / 文档 / 生成        │  嵌入式 Shell    │
│  剧本·季·集  │  Markdown · 物料 · Comfy  │  PTY · 快捷启动  │
└─────────────┴──────────────────────────┴─────────────────┘
```

**日常流程（建议）**

1. 在左侧打开或新建剧本 / 季 / 集目录。  
2. 中间切到 **文档**：多 Tab 写 Markdown（高亮、大纲、预览、`Ctrl+S`）。  
3. 需要看图、视频、音频时切到 **素材**；可导入、过滤、预览。  
4. 右侧用快捷启动打开 opencode / dsh-tui 等；需要上下文时用引用快捷键填入路径。  
5. 要出图/视频时切到 **生成**：选模板、填表单、提交 Comfy；看完结果可跳到素材目录。  
6. 关闭程序若有未保存文档，会提示保存或放弃；处理后再关一次即可退出。

常用快捷键：`Ctrl+P` 全局搜索 · `Ctrl+S` 保存 · `Ctrl+Shift+O` 大纲 · `Ctrl+Alt+K`（可改）发送 Agent 引用。

## 功能概览

| 模块 | 做什么 |
|------|--------|
| **项目树** | 剧本/季/集识别；过滤与新建；文件操作；创作进度；目录监视与拖放 |
| **文档** | 多 Tab Markdown（高亮、行号、大纲、预览）；关 Tab / 退出时未保存提醒 |
| **素材** | 网格浏览、类型过滤、导入；图/视/音预览 |
| **生成** | ComfyUI 模板与动态表单；多服务器；任务结果预览与回跳素材 |
| **Shell** | 多 Tab 真实 PTY；可配置启动命令与工作目录；按项目恢复会话结构 |
| **工作区记忆** | Tabs、选中项、树展开、文档光标/滚动等跨启动恢复 |
| **设置** | 项目根、主题与字号、Shell 快捷启动、Comfy 实例、引用快捷键 |

更细的架构与缺口见 [docs/方案.md](docs/方案.md)；Comfy 接入见 [docs/ComfyUI集成方案.md](docs/ComfyUI集成方案.md)。

## 安装与运行

**用安装包（推荐）**

- 安装程序：`dist/AIReelStudio-0.1.0-Setup.exe`  
- 绿色包：`dist/AIReelStudio-0.1.0-windows-x64.zip`（解压即用）

**从源码跑**

```bash
flutter pub get
flutter run -d windows
```

**打 Release 包**

```bash
powershell -ExecutionPolicy Bypass -File scripts/pack_windows.ps1
```

需本机已装 Flutter；安装器还依赖 [Inno Setup](https://jrsoftware.org/isinfo.php)。产物默认输出到 `dist/`。

## 技术栈（简）

Flutter / Dart · Riverpod · 嵌入终端（kyroon_pty + flterm）· media_kit · window_manager · SharedPreferences

平台优先级：**Windows（主）** → Linux / Android（工程壳，非正式分发）→ 当前无 macOS 工程。

---

## 已知限制

- 搜索为内存扫描，无 SQLite 全文索引  
- 创作进度存在本机偏好，不写项目内 meta 文件  
- Shell 恢复会话结构与启动命令，不回放终端屏幕历史  
- 面板宽度不持久化；部分顶栏入口尚未接线
