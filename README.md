# AIReelStudio

面向 **AI 短剧 / 短视频** 的本地创作工作台：在真实项目目录上，把「看目录、改剧本、预览素材、跟 Agent 协作、调 ComfyUI」收进同一个三栏窗口。

> 版本 **v0.1.1** · Windows 优先 · 可用预览  
> 最后更新：2026-09-17

---

## 为什么用它

短剧团队常用「文件夹 + Markdown + 本地 Agent / Comfy」流水线，却要在资源管理器、编辑器、终端、浏览器之间反复切换——路径对不上、上下文丢、素材和剧本各开一窗。

**AIReelStudio 不另起云端 CMS，也不替代文件系统。**  
项目根仍是你指定的本地路径或 UNC；软件只做专用桌面壳，把已有目录变成可视化工作台。

| 痛点 | 本程序怎么解 |
|------|----------------|
| 剧本/季集目录深，翻文件夹慢 | 左侧树按剧本 / 季 / 集识别；过滤、原地建档、进度徽章、定位滚动 |
| 改稿与素材脱节 | 中间栏用分段控件在文档 / 素材 / 生成间切换；树与素材可互相跳转 |
| Agent 在外部终端，手打路径 | 右侧嵌入真实 PTY；引用当前文件/选区；OpenCode 可列会话、切换、恢复 |
| 生成与项目目录分离 | 内置 Comfy 生成面板；模板落在项目 `.aireel/`；结果可预览并跳回素材栏 |

## 界面骨架

首次启动进入设置，选择**项目根目录**（如 `D:\dramas` 或 `\\nas\share\scripts`）。  
仓库里的 `scripts/` 是**打包脚本**，不是创作项目根。

```
┌──────────────┬────────────────────────────────┬──────────────────┐
│  项目树       │  顶栏 · 素材 / 文档 / 生成      │  嵌入式 Shell     │
│  剧本·季·集   │  网格/列表 · Markdown · Comfy  │  PTY · 快捷启动   │
│  右键与拖放   │  切换不丢状态                     │  OpenCode 会话    │
└──────────────┴────────────────────────────────┴──────────────────┘
```

中间三个主界面是一组**分段切换**（图标 + 名称；文档带打开数徽章）。切走后再回来，目录和编辑器不必重开。左右栏宽度可拖；窗口最大化状态会记住。

**建议日常顺序**

1. 左侧打开或新建剧本 / 季 / 集。  
2. **文档**：多 Tab 写 Markdown。  
3. **素材**：网格或列表看图/视频/音频；可导入、拖放、截帧。  
4. 右侧快捷启动 opencode / dsh-tui；用引用快捷键把路径填进智能体。  
5. **生成**：选 URL 与模板、填表单、提交 Comfy；结果跳回素材目录。  
6. 关闭时若有未保存文档，先保存或放弃，再关一次即可退出。

## 功能说明

### 项目树

- **语义解析**：按路径深度识别剧本根、季容器（`剧集` / `季` / `seasons` 等）、季、集；物料文件夹先列一层，展开再懒加载。  
- **过滤**：顶栏按名称过滤可见节点。  
- **选中策略**：单击选中目录（不抢切中间栏模式）；双击/箭头展开；Ctrl 单击多选。仅当中间已在素材栏时，选目录会同步网格当前路径。  
- **原地编辑**：新建文档 / 文件夹、重命名都是行内输入，不是系统对话框。  
- **进度徽章**：目录可设创作进度（记在本机偏好，不写项目 `meta.json`）。  
- **目录监视**：周期扫描外部增删（NAS / 资源管理器拷贝），树与素材一起刷新。  
- **定位滚动**：从文档标签「在目录树中定位」时，会展开祖先；目标若不在视窗内则滚到中间。  
- **跳到素材**：右键「在素材栏里查看」——切到素材栏；目录则进入该夹，文件则进入父夹并高亮该项。素材栏已打开但路径不对时会改路径。

### 文件系统操作（树与素材共用）

左右共用一套右键菜单与快捷键，行为跟资源管理器接近，但目标始终是项目内路径。

| 能力 | 细节 |
|------|------|
| 打开 | 文件进文档 Tab 或媒体预览；目录可「在当前目录查看」 |
| 资源管理器 | 在系统资源管理器中显示该项 |
| 终端 | 「在终端打开」：展开右侧 Shell，并请求以该目录为 cwd 开/切 Tab |
| 导入 | 向当前或指定目录挑文件导入 |
| 剪贴板 | 剪切 / 复制 / 粘贴；多选时菜单只保留批量剪贴与删除 |
| 路径 | 复制绝对路径、相对项目根路径、文件名 |
| 视频 | 截取首帧 / 末帧 |
| 删除 / 属性 | 删除有确认；属性看基本信息 |
| 拖放 | 树 ↔ 素材、素材内部；默认为移动，Ctrl 为复制；也接受从资源管理器拖入 |
| 快捷键 | 焦点在树或素材时：`Ctrl+C/X/V/A`、`Delete`、`F2`、`Enter`、`Esc`、`Backspace`（素材上一级）。编辑器与终端里的同类按键不会被文件操作抢走 |

空白处右键（素材栏）保留粘贴、新建、导入、终端、显示路径，不含删除重命名。

### 中间栏 · 文档

- **多 Tab**：打开多个 Markdown / 文本；脏标记；关闭 Tab 或退出时未保存会询问。  
- **编辑**：语法高亮、行号、`Ctrl+S` 保存；光标、滚动、选区跨启动恢复。  
- **大纲**：Markdown 标题轨；`Ctrl+Shift+O` 开关；可钉住。  
- **预览**：编辑 / 渲染切换（不是左右分屏）。  
- **标签右键**：关闭、关闭其他、关闭右侧、关闭全部；在资源管理器显示；**在目录树中定位**；复制绝对 / 相对路径 / 名称。  
- **Agent 引用**（默认 `Ctrl+Alt+K`，设置里可改）：无选区写入 `@相对路径`；有选区写入 `#L12` 或 `#L12-L34`。只填入已识别的智能体输入区，**不回车**。原始 PowerShell 不会填。

### 中间栏 · 素材

- **两种视图**：网格 / 列表（列：名称、修改时间、类型、大小）；列宽与排序记住。  
- **导航**：面包屑与历史前进后退；与左侧树的当前目录双向同步（树不强制切到素材，除非你明确「查看」）。  
- **过滤**：按媒体类型筛。  
- **预览**：单击打开图 / 视 / 音；列表行悬停小窗预览（视频要点播放才挂解码器）。  
- **高亮跳转**：从生成面板或树「在素材栏里查看」可指定文件列表，进入目录后选中对应项。

### 中间栏 · 生成（ComfyUI）

不做网页套壳，也不做节点编辑器。走 HTTP API：导入 Comfy **API Format** JSON。

- **三块模型**：项目模板库（`.aireel/comfy/templates/`）· 全局多 URL（设置）· 每 URL 绑定哪些模板（`.aireel/comfy/bindings.json`）。  
- **生成面板**：选实例、绑定/解绑模板、填暴露字段、提交任务；看进度与输出。  
- **结果回跳**：打开输出目录，或高亮本次产物并切到素材栏。  
- **模板库**：导入、重配暴露字段、删除；热加载项目内文件变更。  
- 暴露配置跟**模板**走，不跟某一 URL 私有一份图。

更细的数据约定见 [docs/ComfyUI集成方案.md](docs/ComfyUI集成方案.md)。

### 右侧 Shell

- **真实 PTY**（`kyroon_pty` + flterm），多 Tab；可显隐。  
- **快捷启动**：设置里配置名称、命令、cwd（项目根或当前选中目录）。点芯片把命令发进当前终端。智能体已在跑时，会问是否新开 Tab。  
- **「在终端打开」**：用目标文件夹作 cwd。智能体 Tab 不会为切目录乱发 `Set-Location`（除非这次启动明确要选中目录）。  
- **OpenCode（当前 Tab 的 TUI 仍存活时）**  
  - 左下角「会话」：列出该工作目录下的根会话（更新时间、当前项区分）。  
  - 列表先出缓存再后台刷新，避免每次等 CLI。  
  - 行内重命名、行内确认删除（删完列表仍开着并刷新）。  
  - 优先 `POST /tui/select-session` 在同进程切会话；不行再带 `-s` 重拉。当前会话以 `/tui/active-session` 为准。  
  - 退出 OpenCode 后宿主终端会静默软恢复，不必整 Tab 死掉。  
- **启动图标**：OpenCode / DeepSeek 等在标签与快捷启动上显示品牌图。  
- **跨启动恢复**：记住 Tab 结构、cwd、启动命令、显隐。仅当退出时该 Tab **仍是活着的智能体**才会自动再拉起；已退回普通 Shell 的只保留命令与 session id，供你手动再点。不回放屏幕历史。

### 全局搜索 · 设置 · 记忆

- **`Ctrl+P`**：文件名 + Markdown 正文（内存扫描，最多展示 200 条）；键盘上下选择，回车打开。无 SQLite 全文索引。  
- **设置**：项目根；界面 / 编辑器 / 终端字号；主题；快捷启动；Comfy 多实例（启用开关）；Agent 引用组合键；关于页读包版本。  
- **工作区记忆**：树展开、打开的文档 Tab、当前文件/目录、中间栏模式、各文档光标/滚动/选区。按项目根分份。  
- **素材栏偏好**：视图、列宽、排序单独持久化。

## 安装与运行

**用安装包（推荐）**

- 安装程序：`dist/AIReelStudio-0.1.1-Setup.exe`  
- 绿色包：`dist/AIReelStudio-0.1.1-windows-x64.zip`（解压即用）

**从源码跑**

```bash
flutter pub get
# 首次：镜像拉取 opencv.full（约 160MB，已有则跳过），并写入 tools/opencv-full/env.ps1
powershell -ExecutionPolicy Bypass -File scripts/fetch_opencv_full.ps1
. .\tools\opencv-full\env.ps1
# 让 dartcv4 用本地预编译包（不要源码编译）
powershell -ExecutionPolicy Bypass -File scripts/patch_dartcv_local_opencv.ps1
flutter run -d windows
```

**打 Release 包**

```bash
powershell -ExecutionPolicy Bypass -File scripts/pack_windows.ps1
```

`pack_windows.ps1` 会自动拉取 OpenCV、打补丁再编译。需本机已装 Flutter；安装器还依赖 [Inno Setup](https://jrsoftware.org/isinfo.php)。产物默认输出到 `dist/`。

抽帧使用 `opencv_dart`（`CAP_PROP_POS_FRAMES` 直接取末帧）；原生 OpenCV SDK 不进 git，缓存在 `tools/opencv-full/`。

## 技术栈（简）

Flutter / Dart · Riverpod · 嵌入终端（kyroon_pty + flterm）· media_kit · opencv_dart · window_manager · SharedPreferences · desktop_drop

平台优先级：**Windows（主）** → Linux / Android（工程壳，非正式分发）→ 当前无 macOS 工程。

## 已知限制

- 搜索为内存扫描，无 SQLite 全文索引  
- 创作进度只存在本机偏好，不写项目内 meta 文件  
- Shell 恢复会话结构与启动命令，不回放终端屏幕缓冲  
- 左右栏宽度本次启动内可拖，不写入偏好  
- OpenCode 会话列表依赖本机 `opencode` CLI 与其本地库；非 OpenCode 的智能体没有同等会话面板  
- 素材/树没有标签系统；没有独立的「角色库 / 生成清单」页
